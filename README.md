# What are we eating?

## Repository
<https://github.com/Nazyam99/FinalProposal.md.git>

## Description
This program will be a fun way to select through different options and help you decide on what to eat, because as we all know it's one of the hardest decisions to make.

## Features
- Feature 1
	- Present user with three sets of initilization questions in order to narrow down options.
- Feature 2
	- based on what type of meal (breakfast, lunch, or dinner) user will be presented with a flavor pallette to help them decide futher the type of meal they want.
- Feature 3 
	- Finally the list of options narrows after each of users answers until they finally land on a meal they want.

## Challenges
- I will be using the practice we had of asking user for input and producing a different response based on the answer.
- I will be implementing the use of appearing images of food.
- I want to be able to implement having the user select the image of a flavor which results in another set of images that match that flavor for each flavor option in the game.

## Outcomes
Ideal Outcome:
- Enough options will be given but still help to narrow it down for users to be able to decide on a meal option based on their preferences and any dietary resctrictions they may have.

Minimal Viable Outcome:
- easy user interface, simple questions and only clicking buttons and no typin answers for the user so it doesn't make the decicion of finding what meal or snack appeals to them the most?
